# Meal Planner 做饭规划

## 👉 [点这里直接打开 / Open the app](https://kf20031213.github.io/meal-planner/)

无需下载、无需安装，在浏览器里直接使用。
No download or install needed — it runs right in your browser.

把小红书上刷到的菜谱，变成可以直接买菜和做饭的清单。

## 功能 Features

- 搜索菜名并跳转小红书，或粘贴帖子 / 上传截图，自动识别食材和步骤
- 菜谱卡片，区分"必需"和"可选"食材
- 多道菜的食材合并成一份购物清单
- 冰箱分区，记录家里现有的食材
- 按类别整理的菜谱本
- 中英双语界面

数据只保存在你自己的浏览器里，没有后端。
